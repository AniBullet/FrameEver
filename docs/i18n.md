# Interface languages (GPUI app)

FrameEver's GPUI app ships in English and Simplified Chinese. The language follows the system unless the user picks one in Settings → General → Language (stored as `general_settings.language`: `"en"`, `"zh-CN"`, or absent for "follow system").

## How it works

- `src/i18n.rs` holds the current language and the lookup. English text is the key; there is no separate key name.
- `t!("Text")` returns the text in the current language as `&'static str`. Use it wherever a `&'static str` or `impl Into<SharedString>` is expected.
- `t!("Version {version} is ready", version = value)` returns a `String` with named placeholders filled. Never translate a `format!` string; turn positional `{}` into named placeholders and use `t!` with arguments.
- `n!("Text")` only marks text for translation and returns it unchanged. Use it inside `const`/`static` tables, where a function call is not allowed, and translate at the display site with `tr(value)` (`crate::i18n::tr`).
- `tc!("context", "Text")` is for English words that need different Chinese in different places, such as "Light" (theme 浅色, font weight 细, strength 轻度). Its entries live in `CONTEXTUAL` in `src/i18n/zh_cn.rs` as `(context, english, chinese)`.
- Chinese lives in `src/i18n/zh_cn/<area>.rs` as `(english, chinese)` pairs. Missing entries fall back to English. The same English may appear in two area tables only with the same Chinese.
- Tests in `i18n.rs` fail when a `t!`/`n!` string has no Chinese entry, when an entry is no longer used, when placeholders differ, or when the same English text gets two different translations.

## What to translate

Translate text a user can see: labels, buttons, headings, descriptions, tooltips, menu items, dialog titles and messages, notifications, empty states, and error messages that reach the UI.

Do not translate:
- log and tracing messages, panic/expect/assert text, test fixtures;
- window titles in `app_windows.rs` and `store::DEFAULT_EXCLUDED_WINDOW_TITLES` (recording uses them to hide FrameEver's own windows);
- ids, store keys, file names, asset paths, URLs, CLI arguments;
- product and format names: FrameEver, Cap, MP4, GIF, HEVC, FPS, Whisper, Parakeet, Windows, macOS;
- font names and preset names that are proper nouns.

## Style for Simplified Chinese

- Write natural, concise Chinese; don't translate word by word. Product name in Chinese text is 帧刻.
- Use full-width punctuation (，。：；？！“”) in Chinese sentences; keep ASCII for keys, numbers and units. Put a space between Chinese and Latin words or numbers only when the original has one at that place (e.g. 打开 macOS 设置).
- Keep ellipses as "…" and keyboard keys as written (Ctrl+Shift+F9, Space → 空格 only as a plain word).
- Buttons are verbs: 保存, 导出, 开始录制.

## Fonts

The UI font follows the language: Inter for English, MiSans for Simplified Chinese (`theme::ui_font()`). Both are embedded. Inter (SIL OFL 1.1) is committed under `assets/fonts/`; MiSans is fetched by `pnpm fe setup` because its license allows embedding in an app but not redistributing the font files, and the app credits it in the Settings sidebar as the license requires. Setup rewrites only the OS/2 weight class of the four MiSans files to 400/500/600/700, because MiSans ships non-standard values (330/380/520/630) that would make Windows pick the next weight up.

Proper nouns stay in English in the Chinese UI (CLI, Webhook, PATH, Shell, model names); a one-line Chinese explanation at the top of the page is enough.
