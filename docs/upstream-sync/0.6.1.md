Branch `merge/upstream-0.6.1`. Merge base `78dd5c9f` (2026-01-30); upstream `0da8f6d4d` (0.6.1, 6082 commits ahead). Decisions: ADR-0001 to ADR-0004.

The GPUI app reads files out of the Tauri app's tree by relative path: Tauri `src-tauri/src/recording_start_sound.rs` (via `#[path]`), plus `src-tauri/{icons,sounds,assets,binaries,test-data}` and `src/assets/music`. Missing ones were restored from upstream; our existing files (branding icons) were kept. It also `include_bytes!`ed files from directories we never take: onboarding sky art from `apps/web/public/backgrounds/clouds/` (now `apps/desktop-gpui/assets/onboarding/clouds/`) and test videos from `apps/media-server/src/__tests__/fixtures/` (now `apps/desktop-gpui/tests/fixtures/`). These are local deviations in `src/assets.rs`, `src/editor_clips.rs`, `src/import.rs`, `src/upload/verify_tests.rs`; re-apply on future merges. When the Tauri app was deleted (AniBullet/FrameEver#2) its sounds, editor music and backgrounds, onboarding music, cursor icons and test videos moved into `apps/desktop-gpui` (`assets/`, `test-data/`), and the sidecars are staged in `apps/desktop-gpui/binaries/`.

GPUI build prerequisite: run `bash scripts/prepare-gpui-dependency.sh` once; it clones `wingleeio/zed` at the pinned rev into `../zed-cap` and applies `apps/desktop-gpui/patches/*.patch`. FFmpeg comes from `target/native-deps` via the local `.cargo/config.toml`. Needs a recent stable Rust (zed's gpui uses `std::hint::cold_path`; 1.93 fails, 1.99.1 works); the root workspace stays on 1.88 via `rust-toolchain.toml`.

## Running the GPUI app for testing

`pnpm fe dev` builds the app and runs it on an isolated test profile in `apps/desktop-gpui/target/testdata/` (settings, recordings, logs), with FFmpeg's DLLs on `PATH`; `--watch` rebuilds and relaunches on save, `--lang zh-CN` starts it in Chinese. See `BUILD.md` and `docs/agents/debugging.md`.
